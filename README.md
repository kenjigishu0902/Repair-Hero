# Repair Hero

フェニちゃんを操作して、バグに侵食されたリペアグリッドを修復するブラウザ向け3Dアクションゲームです。Three.jsだけで動作し、PCとスマートフォンの両方に対応しています。

## Stage 1

1. ステージ内のリペアコアを5個回収する
2. バグ獣・グリッチドローンを突破する
3. ダークバグ・ガーディアンを倒す
4. 起動した浄化ゲートに入る

## 操作

| 操作 | PC | スマートフォン |
|---|---|---|
| 移動 | `WASD` / 矢印キー | 左スティック |
| ジャンプ | `Space` | `JUMP` |
| 攻撃 | `J` / `X` | `ATTACK` |
| ダッシュ | `K` / `Shift` | `DASH` |

## 主な実装

- 既存フェニちゃんモデルのボーンを使った手続き型アニメーション
- 待機・歩行・走行・ジャンプ・落下・着地・攻撃・ダッシュの状態遷移
- 予備動作とクールダウンを備えた敵AI
- 近距離攻撃、射程制限付き敵弾、ダメージ、無敵時間、ノックバック
- リペアコア、回復チェックポイント、ボス戦、ゴール、クリア・ゲームオーバー
- 軽量な手続き型3D敵モデル3種
- Web Audioによる効果音、パーティクル、カメラ演出
- 4Kテクスチャを1Kへ軽量化したゲーム用GLB（元モデルへのフォールバック付き）

## 構成

- `js/main.js` — ゲーム進行、入力、戦闘、AI、演出
- `js/model-factories.js` — 敵とアイテムの軽量3Dモデル
- `assets/feni-game.glb` — ゲーム用に最適化したフェニちゃん
- `Meshy_AI_Character_output.glb` — 元のフェニちゃんモデル

GitHub Pagesではリポジトリのルートをそのまま公開できます。
