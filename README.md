# Repair Hero

フェニちゃんを操作して、大自然を侵食する機械バグ軍団を修復するブラウザ向け3Dアクションゲームです。Three.jsだけで動作し、PCとスマートフォンの両方に対応しています。

## Stage 1

1. ステージ内のリペアコアを5個回収する
2. バグ獣・グリッチドローンを突破する
3. ダークバグ・ガーディアンを倒す
4. 起動した浄化ゲートに入る

## 操作

| 操作 | PC | スマートフォン |
|---|---|---|
| 移動 | `WASD` / 矢印キー | 左スティック |
| 二段ジャンプ | `Space` | `JUMP` |
| 攻撃 | `J` / `X` | `ATTACK` |
| 吹き飛ばし攻撃 | `F` | `BLOW` |
| ダッシュ | `K` / `Shift` | `DASH` |
| 回避ロール | `L` / `C` | `ROLL` |
| 必殺技 | `R` | `必殺` |
| カメラ切替 | `V`（`Q` / `E`で回転） | `CAM` / 画面スワイプ |

## 主な実装

- 既存フェニちゃんモデルのボーンを使った手続き型アニメーション
- 腕を自然に下ろした待機、表情変化、まばたき、歩行・走行・二段ジャンプ・着地・攻撃の状態遷移
- 無敵時間付き回避ロール、ダッシュ、吹き飛ばし攻撃
- 赤炎エフェクトと「おいどんは諦めない！！」カットインを備えた必殺技 PHOENIX DRIVE
- FOLLOW / CLOSE / WIDEの3視点と、ドラッグ・スワイプによるカメラ回転
- 予備動作とクールダウンを備えた敵AI
- 近距離攻撃、射程制限付き敵弾、ダメージ、無敵時間、ノックバック
- リペアコア、回復チェックポイント、ボス戦、ゴール、クリア・ゲームオーバー
- 装甲・牙・ブレード・キャノン・剣を持つ軽量な手続き型3D敵モデル3種
- 森、山、渓流、草花、土の道で構成した大自然ステージ
- Web Audioによる効果音、パーティクル、カメラ演出
- 4Kテクスチャを1Kへ軽量化したゲーム用GLB（元モデルへのフォールバック付き）

## 構成

- `js/main.js` — ゲーム進行、入力、戦闘、AI、演出
- `js/model-factories.js` — 敵とアイテムの軽量3Dモデル
- `assets/feni-game.glb` — ゲーム用に最適化したフェニちゃん
- `Meshy_AI_Character_output.glb` — 元のフェニちゃんモデル

GitHub Pagesではリポジトリのルートをそのまま公開できます。
